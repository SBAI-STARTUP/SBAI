# SBAI

SBAI is the engineering workspace and platform repository for the SBAI-STARTUP organization. This repository contains top-level organization for documentation, applications, services, AI assets, infrastructure, hardware, and more.

## Repository Layout

Refer to each top-level folder for purpose and contents. Every top-level folder includes a README.md explaining why the folder exists and what it should contain.

Top-level folders

- docs/
- apps/
- services/
- ai/
- packages/
- infrastructure/
- database/
- security/
- hardware/
- robotics/
- satellite/
- operating-system/
- tools/
- scripts/
- assets/
- tests/
- .github/
