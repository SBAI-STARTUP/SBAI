# SBAI Architecture Diagrams

## Purpose

This directory contains visual documentation supporting the SBAI Enterprise Architecture.

## Diagram Types

- System Context
- Layer Diagrams
- Domain Models
- Module Relationships
- Sequence Diagrams
- Deployment Diagrams
- Data Flow Diagrams
- Component Diagrams
- Network Diagrams

## Standard

Diagrams should be stored as Mermaid Markdown where possible to ensure they are version-controlled and render directly on GitHub.
