# Enterprise Object ID Standard (EOID)

Version: 1.0

Status: Approved

---

# Purpose

Provide globally unique, immutable identifiers for every enterprise object.

Every resource in SBAI SHALL have one Enterprise Object ID.

---

# Format

PREFIX-NUMBER

Examples

FOUNDER-0001

AI-0104

CAP-0140

DOM-0300

ES-0003

WF-000001

TASK-000001

DOC-000001

MEM-000001

KG-000001

API-000001

MODEL-000001

PROMPT-000001

BOT-000001

SAT-000001

HW-000001

PRODUCT-000001

CUSTOMER-000001

---

# Rules

IDs are immutable.

IDs are never reused.

Deleted objects keep their IDs.

Relationships reference IDs only.
