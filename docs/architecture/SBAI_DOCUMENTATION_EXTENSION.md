# Purpose

This document extends the standard Documentation Architecture with SBAI-specific rules.

These rules apply to every document created inside SBAI.

---

# Founder Governance

The Founder is the constitutional owner of all documentation.

The Founder has exclusive authority to:

- Approve Foundation documents
- Approve Architecture documents
- Approve Security standards
- Approve Enterprise Modules
- Freeze Foundation versions
- Approve constitutional changes

AI may propose changes.

Only the Founder approves them.

---

# Documentation Classification

Every document must include one classification.

Available classifications:

- Public
- Internal
- Confidential
- Founder Only
- Constitutional

Example:

Classification: Founder Only

# Foundation Freeze

After SBAI Foundation v1.0:

No document may change the Foundation architecture without Founder approval.

Breaking architectural changes require a new Foundation version.

---

# AI Rules

AI assistants may:

Generate drafts

Suggest improvements

Review consistency

Generate documentation

AI assistants may not:

Approve constitutional documents

Modify Foundation architecture

Override Founder decisions
