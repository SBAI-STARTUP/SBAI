# Purpose

The Enterprise Resource Model defines every resource managed inside SBAI.

Every AI, workflow, service, platform, and product operates on resources.

# Resource Metadata

Every resource shall contain:

- Resource ID
- Resource Type
- Owner
- Domain
- Capability
- Classification
- Version
- Status
- Created Date
- Updated Date
- Relationships

---

# Design Principles

Everything is a resource.

Resources may reference other resources.

Resources may belong to multiple domains.

Resources are versioned.

Resources are governed.
