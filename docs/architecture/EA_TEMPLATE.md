# Enterprise Architecture Template

Version: 1.0.0

Status: Standard

Owner: Founder

Document ID: EA-028

---

# Purpose

This template defines the mandatory structure for every Enterprise Architecture (EA) document within SBAI.

Every EA document shall follow this template unless explicitly superseded by the SBAI Constitution.

---

# Standard Header

Every EA document shall include:

- Title
- Version
- Status
- Owner
- Document ID
- Related Documents

---

# Required Sections

## 1. Purpose

Describe why the document exists.

---

## 2. Scope

Define what is included and excluded.

---

## 3. Objectives

State the architectural goals.

---

## 4. Architecture

Describe the architecture, models, and design.

---

## 5. Responsibilities

Define ownership and responsibilities.

---

## 6. Dependencies

List all dependent:

- EA documents
- ADRs
- Standards
- Constitutional Modules

---

## 7. Constraints

Document architectural limitations and assumptions.

---

## 8. Security Considerations

Describe security implications.

---

## 9. Future Evolution

Identify planned future improvements.

---

## 10. References

List all related architectural artifacts.

---

# Naming Rules

Every EA document shall:

- Use Markdown
- Follow Identifier Standard
- Follow Documentation Standard
- Maintain semantic versioning

---

# Review Checklist

Before approval, verify:

- Purpose defined
- Scope defined
- Dependencies listed
- Security considered
- References complete
- Constitution compliant
- ADR references valid

---

# Guiding Principle

Consistency across Enterprise Architecture documentation is mandatory.
