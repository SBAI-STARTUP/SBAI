# Purpose

The Navigation Model defines how the Founder moves through the SBAI platform.

Navigation shall remain simple, predictable, and scalable regardless of how many products, AI agents, or services are added.

---

# Navigation Principles

- Consistent across all workspaces
- Minimize clicks to reach important information
- Context-aware navigation
- Fast global search
- Keyboard-first support (future)
- Mobile-first, desktop-ready

---

# Primary Navigation

The primary navigation provides access to the major workspaces.

- Dashboard
- Knowledge
- Architecture
- Projects
- Products
- AI
- Security
- Infrastructure
- Research
- Settings

---

# Secondary Navigation

Each workspace contains its own navigation for workspace-specific features.

Examples:

Knowledge
- Documentation
- Research
- Memory
- Knowledge Graph

Architecture
- Enterprise Architecture
- ADRs
- Standards
- Diagrams

AI
- AI Agents
- Workflows
- Prompt Library
- Models

---

# Global Search

Global Search shall allow searching across:

- Documents
- Projects
- Products
- AI Agents
- Workflows
- Architecture
- Research
- Tasks

Search should support future semantic and AI-assisted capabilities.

---

# Context Navigation

The platform should maintain context while moving between workspaces.

Example:

Architecture → ADR → Related Module → AI Agent → Project

without losing navigation history.

---

# Quick Actions

Provide a universal quick-action interface for common tasks, such as:

- Create document
- Create project
- Create ADR
- Start AI workflow
- Search
- Open recent items

---

# Future Expansion

The navigation model shall support additional workspaces and products without requiring a redesign of the navigation structure.
